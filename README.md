# Vishvanath Mokashi - Professional Portfolio & AI Assistant

A modern, responsive portfolio website with an advanced multilingual AI chatbot featuring voice input/output support.

## 🌟 Features

### Portfolio Section
- **Professional Profile** - Comprehensive introduction and career goals
- **Technical Skills** - Organized by category (Languages, Web Tech, Databases, Core Knowledge)
- **Projects Showcase** - Featured work with technology stack details
- **Education & Certifications** - Academic background and professional credentials
- **Contact Links** - Direct links to social media and chat

### AI Chatbot Features
- **🌍 Multilingual Support** - English, Hindi, Marathi, Gujarati, Tamil, Telugu, Kannada, Malayalam
- **🎤 Voice Input** - Speak to the chatbot using microphone
- **🔊 Voice Output** - AI responds with speech synthesis in selected language
- **📱 Responsive Design** - Works perfectly on desktop and mobile
- **💬 Smart Conversations** - Context-aware responses about profile, skills, projects, education, etc.

## 🛠️ Technologies Used

- HTML5, CSS3, Vanilla JavaScript
- Web Speech API (Speech Recognition & Synthesis)
- Multilingual natural language processing
